# 株式検証室

## 画面デザイン

日本語の明朝見出し、余白、罫線で組んだ編集ページとして再設計しました。生成した独自の挿絵は `src/assets/ledger-city.webp` に保存しています。参照した実際の企業サイト、イラストレーターのクレジット、採用した要素は デザイン調査 に記録しています。

日本株の手元の日足 CSV をブラウザ内で監査・検索し、過去リターンを表示する Sites 用アプリです。2026-09-28 現在、合法的に再配信できる直近日本株データを無料で確保できていないため、自動の「いま買い」候補、将来価格、的中率は表示しません。画面にデータは埋め込まず、アップロードもサーバーに保存しません。

## 起動・ビルド

```sh
npm run build
python -m http.server 8000 -d dist
```

`http://localhost:8000` を開きます。`npm test` で CSV 監査と期間計算を確認できます。外部サーバー、API キー、有料プランは不要です。Sites では `dist/` を静的に配信します。

## CSV 形式と操作

UTF-8 の CSV に `date,code,close` が必須です。`name,volume,adjusted_close` は任意です。日付は `YYYY-MM-DD`、価格は正の数とします。最大10 MB・100,000行。銘柄コードと取引日の重複、未来日、不正価格、列不足は除外して件数を表示します。ブラウザ内処理であり、リロード後にデータは残りません。本人が権利を持つファイルだけ読み込んでください。

1. 概要で CSV を選択します。
2. 銘柄を探す画面でコード・名称を検索します。
3. 銘柄を選び、最終実績終値、履歴、1・3・6・12か月の過去リターンを確認します。
4. 検証結果画面で、下記のスクリプトが生成した JSON を読み込めます。

過去リターンは調整済み終値が両端にあればそれを使い、欠ける場合は終値にフォールバックします。**補正されていない価格の結果は投資判断に使えません**。配当、手数料、税は含みません。月次期間は暦月で対応し、目標日から10日以内の観測値がないと非表示です。

## ローカルでの時間外検証

検証には `adjusted_close` 列が必須です。データはローカルから出ません。

```sh
python scripts/validate.py path/to/prices.csv --output validation.json
```

コード、日付、調整済み終値の不正・重複を拒否します。1・5・20営業日の過去リターンと20営業日の日次変動率から、翌営業日終値で入り20営業日後終値で出る単純リターンを予測します。時点順の70%学習、15%選定、15%最終評価に分け、学習・選定サンプルのラベル終端が次期間に入るものを除外します。ゼロ、学習平均、20日モメンタム、リッジ回帰を比較し、導入済みの場合だけ LightGBM と XGBoost も比較します。検証期間の MAE で一つ選び、最終期間は選定に使いません。260日以上、500サンプル以上などの下限未達ではエラーにします。再学習は同じコマンドを再実行します。サイト公開とは別工程です。

このスクリプトは研究用の最小限の時間外検証です。上場廃止を含む母集団、時点再現済み財務、正式な取引カレンダー、取引コスト、配当、流動性制約、複数ウォークフォワード区間、確率較正、予測区間、ポートフォリオ検証は未実装です。従って JSON が生成されても、サイトは買い候補を表示しません。CSV の権利と価格補正も独立検証できません。ソースが破損または古い場合は再実行を止め、古い結果を現在値に転用しないでください。

## 未対応の判断機能

- 直近株価の合法的な無料公開ソース、正式な株式分割・配当補正、銘柄名変更・上場廃止を含む長期母集団を確保できていません。
- 財務指標の発表日時付き時点再現、業種・市場ベンチマーク、売買単位と概算コスト、配当・税、ポートフォリオ、確率較正・予測区間を実装していません。
- そのため、ランキング、買い推奨、将来価格、1日〜12か月の将来損益、ポジションサイズ、的中率・期待利益をサイトに出しません。画面の履歴検証は予測可能性や利益を証明しません。

秘密情報は不要です。将来 API を追加する場合はサーバー環境変数にのみ保存し、ブラウザに渡さない設計が必要です。
